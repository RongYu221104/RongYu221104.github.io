# 讲义封面生成规则提示词草案

> 状态：待审核。当前仅作为草案保存，不构成项目执行规则；审核通过后再整理进项目 `AGENTS.md`。

你正在为 RongYu's Notes 网站新增或更新一份讲义封面。请先阅读讲义元数据（中文标题、英文标题、学科、类别、页数和文件名），必要时检查 PDF 的目录与摘要，再完成封面设计与验证。

## 设计任务

1. 为每份讲义设计一个专属的中心图案。图案必须直接来自讲义主题中的核心对象、结构或过程，例如群作用图、流形网格、相图、光锥、能级跃迁、场线、波函数或粒子交换轨迹。
2. 不得把同一个主图案换颜色、旋转、缩放或轻微改线后用于另一份讲义。每份封面的整体轮廓、视觉重心和主要几何关系都应可辨识地不同。
3. 先保持网站既有唱片封套系列的统一版式，再在图案层体现主题差异：画布为 `720 x 960` PNG；保留站名、学科/类别、页数、中英文标题和文件名；数学与物理沿用各自现有配色。
4. 中心图案应简洁、平面、可复现，使用有限线条、节点、曲线和色块。避免照片感、3D 渲染、装饰性渐变、无关纹样和拥挤公式。
5. 图案不得与标题、页数或其他文字重叠。缩小到网站货架中的封面尺寸后，主题轮廓仍应清楚。
6. 公式只有在它本身就是主题的关键辨识符且能正确排版时才可使用；不能确定公式时，改用可靠的概念图，不得编造数学或物理内容。

## 实现约束

1. 在封面生成脚本中按讲义文件名建立显式的主题图案映射，保持确定性输出；同一份输入重复生成时结果一致。
2. 新增讲义没有专属图案映射时，生成脚本必须报错，不得自动退回通用随机模板。
3. 生成后检查全部封面数量与讲义数据一致，文件名一一对应，尺寸均为 `720 x 960`，且图像内容哈希不重复。
4. 制作全部封面的联系表进行人工视觉检查，重点确认：主题相关、彼此不同、文字不被遮挡、缩略图可辨识、系列风格一致。

## 输出说明

提交时简要说明每个新增图案采用的主题隐喻，并报告生成脚本、数据对账和视觉检查结果。不要仅以“已随机生成”作为完成依据。
