RYplan 使用说明

开始使用

  • 打开页面会选中今天; 上下滚动日历, 点击日期切换内容.
  • 点击"新增计划"填写任务, 内容会自动保存.
  • 点击"复制到清单", 再在清单中勾选已完成条目.

主标题填写课程名 (如: 微分几何), 副标题填写章节或任务 (如: 第三章 曲率张量 / P52-P68).

日历与长期计划

  • 日期下方的小圆点表示当天已有内容.
  • 点击"框选日期", 可跨月份选择开始日与结束日.
  • 长期计划显示在日历下方; 点击条目可编辑日期, 主题和具体安排.
  • 编辑长期计划时, 点击"添加到预设"可保存当前学习主题.

计划与预设

  • 点击预设标签, 可快速填入当前计划的主标题.
  • "管理预设"可新增或删除常用标题.
  • 计划区仅用于安排; 清单的完成状态不会改动原计划.

清单

  • "循心增痕": 新增计划外条目.
  • "未竟携往明日": 把当天未完成条目移入明日计划.
  • 完成数会显示在栏目标题下方.

存档

  • 数据自动读写 HTML 同级的 ryplan_data.json; 首次使用可能需要目录授权.
  • 备份只需复制该 JSON 文件; 单独分享 HTML 得到的是空白软件.
  • "导入并叠加存档"会追加另一份存档, 并自动去除重复条目.
  • 合并示例: 将存档 A 放在 HTML 同级目录, 再选择存档 B 叠加导入.
  • 不支持自动读写时, 请按顶部提示使用导入与下载存档.

清除

  • 清空数据: 关闭页面, 删除同级的 ryplan_data.json, 再重新打开.
